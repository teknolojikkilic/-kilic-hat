# Ekran Paylaş

Oda kodu olmadan ekran paylaşma. Siteye giren "Ekranımı Paylaş"a basar; siteyi açan herkes o ekranı canlı görür (sığdır / doldur / 1:1, yakınlaştırma, kaydırma, tam ekran, ses).

- Node.js + Express + Socket.IO (sinyal), görüntü WebRTC ile doğrudan tarayıcılar arasında akar.
- Paylaşmak için bilgisayar tarayıcısı gerekir; izlemek telefondan da olur.

```
npm install
npm start
```
